# Affinities

Wiki ID: `mechanics.affinities`

Summonlab has four base affinities: Fire, Earth, Wind, and Water. Every pair produces one of six
proposed rare dual affinities, making ten affinities in the complete design. The base associations
are canonical; dual mechanics and exact combat application are not yet shipped. The canonical
status and rules live in [Affinities](../progression/affinities.md).

Each base affinity matches one combat attribute. The first versioned rule caps a matching nudge at
10% of that attribute's contribution, not 10% of the final outcome. The balance harness exercises
this as a promotion candidate; it is not an automatic level-up grant.

## Base affinities and proposed statuses

- [Fire](fire.md) — Burn
- [Earth](earth.md) — Weight
- [Wind](wind.md) — Lacerate
- [Water](water.md) — Chill

## Proposed dual affinities

- Mist — Shroud
- Lightning — Shock
- Sand — Abrade
- Rot — Decay
- Magma — Melt
- Ice — Freeze

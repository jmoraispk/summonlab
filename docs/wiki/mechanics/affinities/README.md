# Affinities

Wiki ID: `mechanics.affinities`

Summonlab has four base affinities: Fire, Earth, Wind, and Water. Every pair produces one of six
rare dual affinities, making ten affinities total. The canonical rules live in
[Affinities](../progression/affinities.md).

## Base affinities

- [Fire](fire.md) — Burn
- [Earth](earth.md) — Weight
- [Wind](wind.md) — Lacerate
- [Water](water.md) — Chill

## Dual affinities

- Mist — Shroud
- Lightning — Shock
- Sand — Abrade
- Rot — Decay
- Magma — Melt
- Ice — Freeze

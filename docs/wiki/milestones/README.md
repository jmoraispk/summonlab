# Playable milestones

Wiki ID: `milestones.index`

Milestones are player-verifiable integration slices. They are not collections of finished packages:
each one must expose a complete loop, persist its consequences, and answer a small set of product
questions before breadth is added.

## Current focus

- [Living Village](living-village.md) — the minimum deterministic loop from summoning through
  combat, return, and training, deliberately excluding agentic society and tower story.

## Milestone rule

Every milestone must let a reviewer complete and understand this causal loop:

```text
observe state
→ make a bounded decision
→ see the system resolve it
→ inspect consequences
→ make a better next decision
```

A milestone is not complete because each subsystem has an isolated demo. The same hero, skill,
equipment item, monster, reward, and save must cross their relevant surfaces through stable IDs.

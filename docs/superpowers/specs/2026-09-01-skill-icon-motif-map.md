# Proposed skill icon motif map

**Status:** Proposed for owner review

**Date:** 2026-09-01

This document assigns all 456 current canonical skills to narrow visual motif families. It is a
review artifact, not a production manifest. Within each sequence, the first skill is the visual
root and every later skill uses the immediately preceding skill as its proposed primary visual
parent. A one-skill sequence is standalone and needs no family calibration plate.

The current draft contains 124 motif families: 104 multi-skill calibration families and 20
standalone skills. Sequences longer than six members will use multiple calibration plates while
retaining one shared motif ID and visual lineage.

The arrows express visual inheritance, not the complete mechanical prerequisite graph. Mechanical
requirements remain authoritative in the skill tables. A production manifest will expand each
approved assignment with subject, supporting cue, palette, exclusions, paths, and provenance.

## Review questions

Owner review should focus on semantic lineage rather than balance:

1. Does every sequence share a recognizable subject or action grammar?
2. Would any long sequence be clearer as two motif families?
3. Are any neighboring sequences visually indistinguishable despite different names?
4. Should any standalone skill inherit from an existing motif family?
5. Does a proposed visual parent misrepresent the skill even if it produces attractive art?

After approval, the implementation pass converts this review map into one machine-readable record
per skill and validates exact one-to-one coverage against the canonical Markdown taxonomy.

# README visual direction

## Accepted direction

- Lead with heroes and village life. Introduce monsters, equipment, and the tower afterward.
- Tell the intended game story through existing artwork and short narrative passages.
- Include gameplay screenshots, with captions that distinguish prototype captures from the full vision.
- Keep the archive notice small and at the bottom of the README.
- Publish the proposal on `codex/public-archive-readme` for online review.

equipment, matching combat chibis, and an expedition aftermath capture follow.

`approved-review` normal forms in the monster wiki runtime catalog. Equipment images use the approved

image uses the shared City renderer's deterministic review scene.

gameplay capture. Screenshot provenance remains documented in the owning evidence files.

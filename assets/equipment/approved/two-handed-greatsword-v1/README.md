# Approved two-handed Greatsword sources

This source-only catalog contains the seven owner-approved Greatsword masters from Bronze F through
Sunsteel S. Greatsword remains a two-handed, Heavy visual family inside the canonical Sword
mechanical class.

`manifest.json` binds every approved PNG to its historical candidate hash, production result, and
proportion review. `receipts/owner-approval-v1.json` records the owner's 2026-09-07 acceptance of all
seven selections. Historical candidate paths are intentionally absent; the approved files preserve
their bytes exactly and are stored through Git LFS.

These sources are not runtime assets and are not present in `equipment-content-v1`. Runtime export,
content definitions, acquisition, balance, and skill compatibility require separate authorization.

# Equipment visual references

This directory stores Equipment-owned inspiration and comparison sources. Everything here is
**reference-only**: it is not a generated candidate, an approved source, or a runtime asset.

- [Owner weapon inspiration — 2026-09-02](2026-09-02-owner-weapon-inspiration/README.md)

Each reference package must record where its files came from, bind the received bytes with
checksums, state any known rights limitations, and extract only broad design lessons. References
must not be copied directly into production or promoted through the candidate approval path.

# Canonical skill rarity-frame comparison

Status: **owner-selected visual authority; individual runtime exports pending**.

`skill-rarity-option-c-v1.webp` is the web-ready comparison plate selected from the third
prototype set on 2026-09-01. It fixes the seven skill-rarity frame identities in this order:

1. F — weathered iron;
2. E — aged bronze;
3. D — tempered blue steel;
4. C — moonlit silver;
5. B — blackened metal and amethyst;
6. A — champagne electrum;
7. S — ceremonial antique gold.

The plate is a composition and material authority, not a sprite sheet. Do not crop its seven
examples into runtime frames. Reusable transparent frame assets require a separate production pass
that preserves the approved materials, ornament hierarchy, hexagonal silhouette, letter medallion,
and text-safe interior.

`catalog.json` binds the retained reference, the selected source PNG, and the derived WebP with
dimensions and SHA-256 values. The source PNG remains byte-preserved under `sources/`; the WebP is
the bundled wiki image.

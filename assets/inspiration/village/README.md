# Village inspiration

Player-provided visual references for the Village shell and its adjacent gameplay surfaces. These
files are inspiration only: they are not approved runtime art and should not be imported by the
client.

## References

- `mission-packing-dock-reference.png` — primary reference for the five-item navigation dock's
  engraved dark-fantasy treatment, framed icons, gold structure, and cyan active state. Secondary
  reference for assigning Village Inventory supplies to individual members of an exploring party.

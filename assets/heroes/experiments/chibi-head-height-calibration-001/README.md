# Chibi head-height calibration 001

This candidate-only experiment compares four Aear Soro combat-chibi renders whose canonical
prompts request anatomical heights of 3.0, 3.5, 4.0, and 4.5 heads tall.

Round 1 used both the summon portrait and combat chibi as references. It drifted toward ordinary
adult proportions and is preserved only as rejected production provenance. Round 2 uses the existing
combat chibi as the sole edit target, holds the head size constant in the prompt, and reconstructs the
body below the chin. The round-2 outputs are the current visual-review candidates.

The requested numbers are prompt targets, not verified measurements. Generative image editing does
not guarantee exact anatomical ratios, and the visual review records visible drift rather than
presenting the labels as measured fact. The prompt texts, immutable input hashes, source-bound output
receipts, and all eight generated candidates are retained for reproducibility.

No output in this experiment is approved or promoted to a runtime catalog.

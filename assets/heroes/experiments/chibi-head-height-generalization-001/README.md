# Three-hero head-height generalization 001

This candidate-only experiment tests whether one chibi proportion prompt skeleton generalizes across three deliberately different hero silhouettes. Aear Soro, Lanor Beleth, and Brinen Sorel are each edited at prompt targets of 4.0, 4.5, and 5.0 anatomical heads tall.

Each lane uses exactly one immutable existing combat-chibi image as its edit target. Identity, body construction, hairstyle, wardrobe, palette, accessories, expression, painterly register, and canvas remain controlled. Only the requested crown-to-chin versus crown-to-sole relationship changes. The labels are prompt targets, not guaranteed geometric measurements.

All outputs remain review candidates. No approved or runtime catalog is modified.
